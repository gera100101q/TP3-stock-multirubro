# TP3 - Sistema de Gestión de Stock

Sitio web estático que simula un sistema de gestión de stock para un comercio multirubro (kiosco, librería y regalería).

Desarrollado como Trabajo Práctico N°3 de **Laboratorio de Programación** — 6to año G, IPET 249 Nicolás Copérnico (2026).

## Páginas

- `index.html` — Dashboard con tabla de productos destacados por rubro
- `gestion.html` — Formulario para agregar/editar productos e inventario actual
- `ventas.html` — Registro de transacciones y pagos a cuenta de clientes

## Principios de Usabilidad (Steve Krug) aplicados

1. **No me hagas pensar**: navegación consistente en todas las páginas, clase `activo` y migas de pan para que el usuario siempre sepa dónde está.
2. **Minimizar el ruido**: badges de colores para identificar rubros de un vistazo, sin texto extra.
3. **Aprovechar las convenciones**: logo como enlace al inicio, botones rojos = acción principal, verde/rojo para estados de pago.
